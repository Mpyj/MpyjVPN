# 🤝 Contributing to MpyjVPN

First off, thanks for taking the time to contribute! 🎉

## Code of Conduct

Be respectful, inclusive, and constructive. We're all here to learn and build.

## How Can I Contribute?

### 🐛 Reporting Bugs
- Use the [Bug Report](https://github.com/Mpyj/MpyjVPN/issues/new) template
- Include: OS, .NET version, steps to reproduce, expected vs actual behavior
- Attach logs if possible

### 💡 Suggesting Features
- Use the [Feature Request](https://github.com/Mpyj/MpyjVPN/issues/new) template
- Explain the use case and why it would be valuable

### 🔧 Pull Requests
1. Fork the repo
2. Create a branch: `git checkout -b feature/amazing-feature`
3. Follow code style (below)
4. Write clear commit messages
5. Test thoroughly
6. Submit PR with description
